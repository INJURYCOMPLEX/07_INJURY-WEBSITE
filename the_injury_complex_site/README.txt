HOW TO PREVIEW
1. Unzip the folder.
2. Open index.html in Safari, Chrome, Edge, or Firefox.

HOW TO PUBLISH
Upload the entire folder to Netlify, Vercel, GitHub Pages, Cloudflare Pages, or your web host.

BEFORE GOING LIVE
Search index.html for href="#" and replace those with the real Spotify / YouTube / Instagram / contact URLs.

The email field currently demonstrates the interaction but does not send to a mailing-list service yet.
